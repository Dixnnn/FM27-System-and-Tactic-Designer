Getting your squad from FM27

  1. Install the FM27 Tactic Builder plugin once with its setup (see the README).
  2. In FM27 open Squad and switch the view to FM27TFT, the plugin's built-in view (or any view with all attributes; the README lists the columns).
  3. Press F8. The plugin reads your players and opens this page with your tactic.
  4. Without the plugin: export with FM View Exporter (F9) and drop the squad_….csv on the box.
Nothing is uploaded: the file is read inside this page, on your PC, and the page is blocked from using the internet.
