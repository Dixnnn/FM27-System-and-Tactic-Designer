Advanced: role and tuning files

The roles (and their key attributes) and the engine's numbers live in two JSON files. After an FM27 patch you can edit them and load your copy here; it's remembered in this browser.

How to get the export from FM27

  1. Install FM View Exporter once (free; see the README). It adds an F9 export to FM27.
  2. In FM27 open Squad and pick a view that shows all attributes (the README lists the columns, or import the ready-made view).
  3. Press F9 and wait until it stops scrolling. The file appears in Documents\Sports Interactive\FM View Exporter.
  4. Drag that squad_….csv (or .html) onto the box above.

Nothing is uploaded anywhere: the file is read inside this page, on your PC.
