Getting the export from FM27

  1. Install FM View Exporter once (free; see the README). It adds an F9 export to FM27.
  2. In FM27 open Squad and pick a view that shows all attributes (the README lists the columns).
  3. Press F9 and wait until it stops scrolling. The file is saved in Documents\Sports Interactive\FM View Exporter.
  4. Drop that squad_….csv (or .html) on the box.
Nothing is uploaded: the file is read inside this page, on your PC, and the page is blocked from using the internet.
